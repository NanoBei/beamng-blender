原大路西端延伸 7 m 接入回程路，东端继续接考试连接道；平面发卡弯仍通过末端 R10 连接路回到大路。新增回程路作为单向循环道路，中部大路接入时让行。场地出入口接回程直道，图纸中单独标注。3 m 发卡小路上的双箭头表示可选择练习方向，不代表可以双车同时会车。
