# 中国科目二地图模型

这是一个独立的新模型项目目录，与 `output/mountain_hairpin_road/` 中已经完成的发卡弯模型分开。当前仅创建目录和项目说明，尚无场地模型，也未确认科目组合和尺寸。

## 开始前待确认

- 要复刻的地区/驾校/考试场地；如要求符合现行考试标准，需要先确认适用地区和官方来源。
- 包含哪些考试项目，以及各项目是否按考试顺序连成一条路线。
- 场地实际边界、入口/出口和大致尺寸；优先参考用户草图、照片、测量或场地图。
- 目标车辆类型和尺寸，以及要测试的通过性。
- 交付范围：只要带标注的俯视图、Blender 场景，还是还要导出 BeamNG 测试地图。
- 画面风格、场地材质、标线、库位和障碍物细节。

不要把未经确认的示意尺寸描述为全国统一的科目二规范。需求明确后先制作带尺寸和路线方向的俯视草案，确认后再建模。

## 文件规划

- `requirements.md`：用户确认的范围与参数。
- `plan/`：带尺寸的俯视图、项目顺序和修订版。
- `blender/`：逐版本保存的 `.blend` 与可复现脚本。
- `beamng/`：DAE、PNG、关卡配置和最终 ZIP。
- `test-notes.md`：游戏版本、加载结果、驾驶观察与修复记录。

通用建模和导入约定见仓库根目录的 [`AGENTS.md`](../../AGENTS.md) 与 [`docs/BLENDER_BEAMNG_WORKFLOW.md`](../../docs/BLENDER_BEAMNG_WORKFLOW.md)。
