# 科目二场地实景参考图集

用途：为 Blender 建模提供路面、标线、路缘石和环境的视觉参考，再用于 BeamNG 场景制作。

**本文件引用在线原图，图片需要联网查看；不包含离线图片。** 图片不是测绘正射影像，也不是可直接使用的无缝材质。前次尺寸表是旧版参考，不能据此宣称符合现行考试场地标准。

## 主参考：同一套小昆山考场教学俯拍

来源：[《2023 科目二考试技巧图解教程 All In One》](https://www.cnblogs.com/xgqfrms/p/17354063.html)。页面自述为上海小昆山科目二考场；下面四图来自同一篇图解，原始摄影者未独立核实。

保留图片原有教学标注。橙色框、编号、红色手绘线及右侧文字不是场地实体，不应建入模型。

## 给建模 Agent 的使用约束

- 几何尺寸采用经核对的参数文件；照片只作为外观与场景布置参考，不反推精确尺寸。
- 优先选择同一套场地作为视觉基线。本图集建议以前四张的浅灰路面、白色标线、黑黄路缘为主；坡道参考单独明确，不假定颜色或标线形式全国统一。
- 路面基础材质、标线、裂缝与轮胎印、路缘石、植被分别制作。不要将整张航拍照片直接贴在地面上；照片中车辆、阴影、教学标记均不应成为地面纹理。
- 俯视图用于平面关系；坡道高度、竖曲线和挡边侧面还需要尺寸资料或侧面实拍。
- 图片仅列为第三方视觉参考，不代表素材授权。发布模组时采用自制或有相应授权的材质，不把这些原照片当作已授权游戏贴图。
