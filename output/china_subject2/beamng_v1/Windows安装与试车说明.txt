中国 C1 科目二闭环训练场 V1 — 目标 BeamNG.drive 0.39
地图名称：China C1 Subject 2 - Closed Loop
地图 ID：china_c1_subject2_v1

安装
1. 将 china_c1_subject2_v1.zip 复制到运行 BeamNG.drive 0.39 的 Windows 电脑，不要解压。
2. 使用 BeamNG 启动器 Manage User Folder → Open in Explorer 打开当前用户目录。
3. 将 ZIP 放进该目录的 mods 文件夹（不存在则创建）。不要放进 Steam 游戏安装目录。
4. 启动游戏，在 Mod Manager 确认模组启用；在 Freeroam 搜索 China C1 Subject 2。
5. 选择 Exam Start / 考试入口；另有 Main Road / 大路、S Curve / 曲线行驶入口出生点。

场地
考试区域 90 × 60 m，倒库 → 侧方 → S 弯 → 直角 → 坡道 → 回程 → 倒库。
倒库至侧方为 8 m 直连，五项各一处。S 弯两段 135°，外半径 7.5 m、内半径 4 m。
发卡弯、大路、回程路保持平面；科目二坡道为 10% 恒坡与 R30 过渡。
场外只有一层平整草地支撑，避免刚离开边界就掉入虚空；不增加考试项目。
地图提供自由驾驶场地，没有自动考试评分、AI 交通或可驾驶 C63 车辆模组。
原 C63 是 Blender 静态比例参考，不包含在本地图包。请选游戏内轿车或已安装的车辆。

首次试车
- 查看出生点、车头朝向、路面是否承载车辆；初始位置应面向考试路线前进方向。
- 低速完成一圈：倒库、侧方、S 弯、直角、坡道上坡及下坡、回程闭环。
- 查看路缘碰撞、坡道接缝、停车线、发卡弯及大路路口；确认没有穿地或异常弹跳。
- 查看白线、黑黄路缘和中文标牌是否完整，没有 NO MATERIAL 或缺失贴图。
- 保存、退出并重新加载一次，确认出生点和资源仍正常。
