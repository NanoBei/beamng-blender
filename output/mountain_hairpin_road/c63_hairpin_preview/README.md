# C63 发卡弯俯视比例检查

本目录为 V14 的独立摆位预览；道路、土坡、石块和 C63 尺寸不变，V14 原文件仍保留大路停车位置。

- `c63_c1_top.png`：上方第一个发卡弯 C1，车身朝向沿弯顶切线，车身中心从原道路中心线向内弯借位 0.50 m；垂直正交俯视，含 1 m 标尺。
- `c63_c1_static_preview.blend`：上述摆位场景。
- `c63_c1_centerline_top.png`：未向内借位的初始对照图，车头/车尾外角越过铺装边缘、贴近石块。
- `placement_report.json`：当前摆位、高程及轮胎最低点与路面距离。
- `centerline_report.json`：初始摆位对照数据。

车长 4.756 m、车身宽 1.839 m、含镜宽 2.020 m、轴距 2.840 m；小路直段宽 2.7705 m，发卡弯保留已有局部补角。仅进行刚性参考车的姿态和地面贴合，不模拟悬架或轮胎变形。

该图表示某个静态姿态，不能证明能从入口连续驶入、驶出，不能据此判定一把通过或倒车次数。前轮未模拟转向；需要车辆实际转向限制、完整扫掠轨迹和游戏内测试才能判断动态通过性。当前道路中心线圆弧半径不是车辆转弯半径。

用户提供的 C63 源素材为个人使用许可，本目录 `.blend` 排除公开 Git 上传。来源与实车规格见 V14 README。
