# V19：小路 3 米与大路双车比例

小路由 2.85 m 加宽至 3.00 m，两侧各外移 0.075 m，保留发卡弯内侧补角及入口渐变。附近排水渠、护栏、石块和土坡同步外移；V18 收短后的 7 m 护栏保持原长度，C63 保持小路直段中央的摆位。

大路铺装网格实际边缘为 Y=42.0–46.5 m，净宽 4.5 m，未改动。排水渠位于 Y=46.5–47.24 m，在铺装宽度之外；渠内净宽 0.5 m、深 0.6 m，壁厚试拟 0.12 m。
