# V16：按用户 1 / 2 / 3 标注调整路侧

基于 V15 的 2.85 m 小路与 C63 直段居中场景另存。原有路面顶点/面、4.5 m 大路及车辆摆位完整保留。

## 三处调整

1. 两弯之间直段的内侧/西北侧（土坡侧）：新增约 10.5 m 镀锌波形钢护栏、7 根立柱、连接件和端板，护栏位于原铺装外侧。
2. 同一直段的另一侧/东南侧：去掉贴路石块和原高土坡，试做约 3 m 无防护落差；路缘外 0.4 m 五处采样落差约 2.73–2.82 m。坎底与其他既有路段和地形过渡，陡面以裸土为主。3 m 是本次试拟值，并非用户提供的实测高差。
3. 上方进弯直段后半段至 C1 外弯土坡侧：真实挖空 U 形排水渠，净宽 0.5 m、深 0.6 m，墙厚约 0.12 m；渠外再接土坡、植被和石块。沟槽从入口渐变之后接起，避免伸进大路。沟底与五处竖向射线深度已核验。

护栏及沟渠形式用于场景试做，并非道路工程认证设计。排水渠暂不模拟水流，也未连接完整排水管网。

## 文件

- `road_trial_v16_roadside_layout.blend`：完整新版场景，仅本地保存。
- `overview.png`、`top_view.png`：斜俯视及垂直俯视预览。
- `adjust_roadside.py`：重建脚本，需打开 V15 直路 C63 场景后运行。
- `validation_report.json`：铺装几何不变、车辆姿态不变、悬崖落差、沟槽深度、石块调整记录。

C63 为用户提供的个人使用许可车模，原始及衍生 `.blend` 不上传公开仓库，公开保存脚本、预览和记录。

**BeamNG V2 仍是 V12 的 2.7705 m 旧路宽与旧路侧布局，本轮没有更新游戏包。** 新增护栏需要简化碰撞代理，沟渠/挖空地形也需要加入新的导出清单并在 Windows 游戏里验证后才能作为可驾驶地图测试。
