# V10 发卡内弯高程修正（待用户看图确认）

用户指出内弯接合处与实地不符，存在过大的高低落差，要求稍向弯心内倾并缓和接坡。本版据此修改两个发卡弯的真实网格高程。

- 场景：`road_trial_v10_smooth_hairpins.blend`。
- 路面 XY 顶点和边界完全保留，大路仍是水平标高 0。
- 弯道平均纵坡试调为约 3°，弯心附近横向内倾系数为 3%（约 1.7°）；两端各约 5 m 逐渐接回 10° 直路。
- 修复方式：补角区域使用无角度奇点的平滑高程面，改善瘦长三角形的对角线连接，同时把相邻土坡接到新路缘。
- 弯道降坡后末端中心标高约 -6.073 m，较 V9 的 -8.874 m 抬高约 2.801 m。并非在原有固定高差下重新分配坡度。
- `c1_before.png` 与 `c1_after.png` 使用同一相机；另有 `c2_after.png` 和 `hairpins_overview.png`。

几何检查见 `surface_report.json`：XY 顶点未移动、水平大路高度误差为 0、2410 个共用路缘顶点高差小于 0.000001 m；两弯附近网格面最大坡度分别约 9.98° 和 10.53°（统计范围包含接坡，不代表中心线平均纵坡）。全路段原有的 842 个超过 30° 的路面三角面已消除。入口段仍保留原 V9 形状，局部横向面坡度最高约 22.23°。

本版只完成 Blender 模型及离线几何检查，等待用户查看近景。BeamNG ZIP V1 仍对应 V9，尚未导出 V10 游戏包，也没有游戏内驾驶验证。

重建：用 Blender 后台打开相邻 V9 的 `.blend`，执行本目录 `smooth_hairpins.py`。该脚本引用同目录 `road_profile.py`；不依赖已删除的 V1–V8 文件。运行前保留已有 V10 成果，避免覆盖尚未备份的调整。
