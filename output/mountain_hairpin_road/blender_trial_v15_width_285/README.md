# V15：小路宽 2.85 米试调

用户要求将小路从 2.7705 m 加宽至 2.85 m。本版基于 C63 发卡弯俯视场景另存，旧版本保留。

- 小路标准直段宽 2.85 m；两侧各增加 0.03975 m。入口原喇叭口渐变、两处发卡弯局部补角保留，弯道侧边向外平顺偏移，不将整个道路等比放大。
- 大路保持 4.5 m，C63 实车尺寸、姿态和向内弯借位 0.5 m 的位置保持不变。
- 土坡共边、土坎、石块、草丛和水泥切缝随路缘调整；路面原顶点高程保留。
- `road_trial_v15_width_285.blend`：新版完整场景。
- `c63_c1_top_285.png`：与上次相同相机、比例尺、车辆摆位的俯视图。
- `width_validation.json`：六处直段几何宽度、共边接缝、路面三角形和石块顶点净空检查。

宽度指 XY 俯视净铺装宽度；入口渐变和发卡弯补角处并非等宽。静态图不能证明一把转过，未进行车辆扫掠轨迹或 BeamNG 驾驶验证。

**现有 BeamNG V2 ZIP 仍是 2.7705 m 旧宽度，本轮未重新打包。** 后续导出需要切换 V15 源文件，并更新小路对象名 `Road_Surface_Small_Concrete_2p85m`，不能直接声称 V2 已包含此变更。

C63 为用户提供的个人使用许可素材，衍生 `.blend` 仅本地保存，已通过本目录 `.gitignore` 排除公开上传。
