家乡双发卡弯驾驶测试 V2（Blender V12）

一、安装
1. 复制 tight_hairpin_drive_v2.zip 到 Windows 电脑，不解压。
2. 在 BeamNG 启动器选择 Manage User Folder → Open in Explorer。
3. 将 ZIP 放入该用户目录的 mods 文件夹。
4. 启动游戏，在 Freeroam 搜索 Hometown Hairpin Drive V2，选择 Main Road 出生点。
5. 建议暂时停用旧 Tight Hairpin Test V1，避免选错版本。

二、试车顺序
1. 确认出生在平坦大路，路面有颜色，车辆不穿地；按车辆复位键可恢复。
2. 先低速沿小路中央经过两个发卡弯，检查入口、缓坡接缝是否弹跳或蹭底。
3. 低速逐渐靠近土坡侧：轮胎/车身应与高出路面的土坎、裸露石块发生接触，不能直接穿过。
4. 在游戏里低速尝试越过无护栏路缘：车轮应失去原路面支撑，掉向下方坡地；不应存在看不见的平台挡住车辆。
5. 检查大路护栏能挡住车辆，排水渠会产生真实落轮而不是平面贴图。
6. 保存并重载地图，再检查路面材质、石块和护栏碰撞是否仍然存在。

三、范围
- 参考 A4L 只是 Blender 内的尺寸模型，未作为驾驶车辆装入游戏。可先选游戏内相近车身尺寸和轴距的轿车测试。
- 石块按露出路缘约 20–40 cm、土坎约 10–20 cm 试建；实际露出土面的高度会随坡地变化。
- 水泥路面采用独立干燥硬路面物理基准，摩擦、轮胎、悬架和实际道路数据尚未校准。
- 模型已做离线格式和几何检查，尚未在 BeamNG 内实测，不能承诺首次加载、碰撞表现或真实车辆通过性。

四、出现问题时
记录 BeamNG 版本、问题位置和表现，并保留 beamng.log。
如果地图不显示或载入失败，先检查 ZIP 根目录是否直接为 levels/tight_hairpin_drive_v2/；若关卡存档格式不兼容，用目标版本 World Editor 的空地图模板核对目录与对象格式。
如果护栏/石块穿透、悬崖有隐形支撑或轮胎卡住，不要仅改外观颜色；需要检查 TSStatic 碰撞和实际网格。
