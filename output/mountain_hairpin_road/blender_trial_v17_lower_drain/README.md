# V17：下方直路土坡侧追加排水渠

按用户红色箭头，在 C2 出弯后的下方直路东北/土坡侧新增排水渠，形成“2.85 m 铺装 → 排水渠 → 土坡和植被”。

- 沿用上方沟渠规格：净宽 0.5 m、深 0.6 m，混凝土壁厚约 0.12 m。
- 从 C2 出弯后 2 m 起至末端前 0.15 m，沿直路约 13.85 m，避开狭窄弯内补角。
- 沟槽实际挖空；原贴路石块移至渠外土坡，沟槽内草丛清除。
- 路面几何、大路、V16 护栏、上方沟渠以及 C63 的位置不变。

`road_trial_v17_lower_drain.blend` 是完整新版场景；`overview.png` 和 `top_view.png` 是预览；`validation_report.json` 记录路面及既有设施保持、沟槽六处深度、石块移动检查。
