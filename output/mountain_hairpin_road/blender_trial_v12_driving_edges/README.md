# V12 驾驶练习路缘与碰撞

根据用户要求，把水泥小路调暗为旧水泥灰，把大路柏油调浅；在小路靠土坡处加入略高土坎和裸露石头，悬崖侧保留无防护跌落条件。用户已确认本轮石块突出路面约 20–40 cm、土坎约 10–20 cm 的建模尺寸。

## 模型内容

- 场景 `road_trial_v12_driving_edges.blend`，以 V11 为输入，旧文件保留。
- 大路和小路的路面顶点完全未变：仍为 4.5 m 大路、2.7705 m 小路；两处发卡内弯继续保留 V10 的缓坡、轻微内倾和局部补角。
- 按原有地形高度判断土坡侧、悬崖侧，不把石块放在跌落侧。上坡侧约 18 cm 的土坎直接塑造在地形网格中，无叠加悬浮平面。
- 43 块不规则、半埋的闭合凸石块，最高点高于对应路缘约 23–40 cm；相对于土面的实际露出高度会因当地坡度而不同。石块在铺装外，独立检查投影不侵入水泥路面。
- 悬崖侧在路缘外把已有下降地形收紧，收窄原来的松土肩，不增加护栏或挡坎。抽样点位于路缘外 0.35 m，落差中位约 1.71 m；这不是实地测量值，也不代表全段统一落差。下方仍是原有坡地。
- 参考 A4L 保持在大路上，只用于尺寸对照，不是可驾驶的车辆模组。

## 驾驶碰撞

对应游戏包为相邻 [`beamng_hairpin_test_v2/`](../beamng_hairpin_test_v2/README.md)。道路、土坎/地形、排水渠、石块均导出碰撞表面；护栏使用独立的简化实心梁与立柱碰撞体；草丛、混凝土细切缝、反光片和螺栓不作为单独障碍。

Blender 内隐藏的 `V12_Guardrail_Collision_Only` 集合只供导出。游戏里由不可见但带碰撞的单独 TSStatic 使用；需要在 Windows 实测隐藏状态与碰撞都按预期工作。

本版已完成离线几何检查，没有在 BeamNG.drive 加载、驾驶、撞石或坠落测试。路面摩擦为干燥硬路面的试验基准，尚未按真实道路、轮胎、车速校准。A4L 静态比例车不能证明实际 A4L 的转弯、悬架或碰撞表现。
